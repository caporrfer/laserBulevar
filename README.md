# Láser Bulevar

Propuesta web visual para un centro de depilación láser y estética en Jaén. Está construida con Astro, CSS propio y GSAP, con una experiencia diseñada primero para móvil.

## Desarrollo

```sh
npm install
npm run dev
```

Comprobación de tipos y compilación:

```sh
npm run build
```

## Contenido pendiente de validación

- El número `953 10 19 79` se usa para teléfono y WhatsApp por indicación del propietario de esta propuesta.
- Los precios visibles son ejemplos de presentación y no tarifas verificadas del negocio.
- La disponibilidad exacta de cada técnica o tratamiento debe confirmarse con Láser Bulevar antes de publicar.
- La valoración y el horario son una captura de datos públicos, no información sincronizada automáticamente.
- Las fotografías fueron generadas con IA y no representan el local, su personal ni clientes reales.

Los datos editables están centralizados en `src/config/business.ts` y `src/content/services.ts`.
